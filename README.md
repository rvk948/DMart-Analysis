# D-Mart Sales & Profit Analysis Dashboard

## Project Overview
This project focuses on analyzing D-Mart sales and profitability using Microsoft Excel. It provides insights into business performance through interactive dashboards, KPIs, Pivot Tables, charts, and slicers.

## Key Features
- Sales and Profit KPI Analysis
- Region-wise Sales Analysis
- Category-wise Sales Performance
- City-wise Sales Analysis
- Sales Trend Analysis
- Profit Margin Analysis
- City-wise and Year-wise Profit Analysis
- Interactive Dashboard with Slicers

## Dataset Details
The dataset contains 15,345 sales records with information such as:
- Order ID
- Region
- Category
- Sales
- Discount
- Quantity
- Order Date and Delivery Date
- Customer Type
- Payment Mode
- Profit
- City
- Year

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Analysis
- Data Analysis
- Data Visualization

## Objective
To transform raw sales data into meaningful business insights, identify sales and profit trends, and support data-driven business decisions.

## Key Learning Outcomes
- Data cleaning and preparation
- Business data analysis
- KPI development
- Dashboard creation
- Sales and profitability analysis
- Interactive data visualization
